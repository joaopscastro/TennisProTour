Tennis Pro Tour — UI direction prototypes

Two throwaway visual directions for the same screens and the same invented dataset. Open either and compare. Neither is wired into the app.

Direction A

Broadcast Sports Telemetry

A dark broadcast-booth look: dense squad tables, segmented stat bars, a horizontal bracket with surface-coloured rails, one court-lime accent. Numerals in IBM Plex Mono, display in Saira Condensed.

  • Roster as a dense table (not cards)
  • Tabbed: Roster / Tournament
  • Depth from background steps, no shadows

 Direction C

90s Management Terminal

A monospace terminal aesthetic: box-drawn panels, ASCII bars, bracketed tokens and hotkey tabs, amber-on-black. One font, zero radius, no motion beyond a live blink.

  • Fixed-width terminal layout
  • Panels framed with box-drawing characters
  • ASCII bars for every continuous value
